# TO--DO-LIST-APP

# Python Practice Projects

A collection of beginner Python console programs built and tested in Google Colab.

## Projects

### 1. To-Do App
A simple command-line task manager.

**Features:**
- Add a task
- View all tasks
- Delete a task by number
- Exit the app

**Menu:**
```
--- TO DO APP ---
1. Add Task
2. View Tasks
3. Delete Task
4. Exit
```

### 2. Calculator App
A basic command-line calculator supporting two numbers at a time.

**Features:**
- Addition
- Subtraction (larger number minus smaller number)
- Multiplication
- Division

**Menu:**
```
welcome to my first calculator
press 1 for addition
press 2 for subtraction
press 3 for multiplication
press 4 for division
```

## How to Run

1. Open the notebook in [Google Colab](https://colab.research.google.com/) or Jupyter Notebook.
2. Run each cell in order.
3. Follow the on-screen prompts to interact with the app.

Alternatively, copy the code from a cell into a `.py` file and run it locally:
```bash
python todo_app.py
python calculator_app.py
```

## Requirements
- Python 3
- No external libraries required

## Notes
- These are practice/learning projects focused on control flow, loops, lists, and user input handling in Python.
- The calculator currently does not handle division-by-zero errors (the check is commented out in the code).
